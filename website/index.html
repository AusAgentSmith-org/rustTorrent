rustTorrent is a self-hostable torrent client with a clean web UI, a full HTTP API, and qBittorrent-compatible endpoints for your existing tools. One small binary. Runs anywhere Docker does.

Features

Everything a modern client needs.
Nothing it doesn’t.

01

Web UI

A responsive React interface with a compact table view, detail panes, and dark mode. Manage torrents from any browser, desktop or mobile.

02

HTTP API

Every action in the UI is an API call you can make yourself — add torrents, query state, select files, and stream content programmatically.

03

qBittorrent-compatible endpoints

Speaks the qBittorrent WebUI API, so tools like Sonarr and Radarr connect without special adapters.

04

Full peer discovery

DHT, HTTP and UDP trackers, peer exchange, local service discovery, and UPnP port forwarding — magnets resolve straight from the swarm.

05

Stream while you download

Play media straight out of incomplete torrents over HTTP, with sequential piece prioritisation doing the work behind the scenes.

06

RSS automation

Subscribe to feeds, filter with rules, and let new releases start downloading on their own.

07

Small and self-contained

A single static binary built on Tokio async I/O. The Docker image is a scratch container with just the binary inside.

08

Desktop app

A native Tauri app for Windows, macOS, and Linux with system-tray integration, for people who prefer a window to a browser tab.

09

Memory safe by construction

Written entirely in Rust: no buffer overflows, no data races, no use-after-free. The protocol parsers are additionally fuzz-tested.

Get started

Running in under a minute.

docker run -d --name rusttorrent \
  -p 3030:3030 -p 4240:4240 \
  -v ~/downloads:/downloads \
  ghcr.io/ausagentsmith-org/rusttorrent:alpha

Port 3030 serves the web UI and API; 4240 handles BitTorrent TCP and uTP. Mount your download directory at /downloads.

Open the latest GitHub release and download:
rtbit-<version>-linux-x86_64

A single static binary — no runtime dependencies. The web UI comes up at localhost:3030.

rtbit-<version>-windows-x86_64.exe server start %USERPROFILE%\Downloads

Download the Windows binary from the latest GitHub release, then run it from a terminal. The web UI comes up at localhost:3030.

Linux x86_64 static binary Windows x86_64 .exe binary All builds + SHA256 checksums
